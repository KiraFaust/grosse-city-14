Space Station 14 это ремейк SS13, который работает на собственном движке [Robust Toolbox](https://github.com/space-wizards/RobustToolbox), написанном на C#.

Это репозиторий сервера по Space Station 14 в сеттинге Half Life 2 которое создано для развлечения ее создателей и получения уникального игрового опыта всем остальным.
